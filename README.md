
# Backend для MMPI тестирования

Backend сервис для проведения психологического тестирования по методике MMPI (Миннесотский многофазный личностный опросник).

## Технологии

-  **FastAPI** - современный веб-фреймворк для создания API

-  **SQLAlchemy** - ORM для работы с базой данных

-  **Alembic** - система миграций базы данных

-  **Docker** - контейнеризация приложения

-  **Pytest** - фреймворк для тестирования


## Структура проекта

```
backend/
│
├── src/ # Основной код приложения
│ │
│ ├── handlers/ # HTTP обработчики
│ │
│ ├── models/ # Модели базы данных
│ │
│ ├── schemas/ # Pydantic схемы
│ │
│ └── utils/ # Утилиты и вспомогательные модули
│
├── tests/ # Тесты приложения
│
├── migrations/ # Миграции базы данных
│
└── .github/ # GitHub Actions CI/CD
```

## Быстрый старт
### Использование Makefile

Проект включает Makefile для упрощения разработки:

```bash
# Запуск базы данных
make start-db

# Применение миграций
make migrate

# Запуск приложения
make start-app
  
# Запуск тестов
make test
  
# Остановка всех сервисов
make stop

# Просмотр логов
make logs
```  

## Разработка

### Миграции базы данных
Проект использует **Alembic** для управления миграциями базы данных. Все миграции находятся в папке `migrations/`

### Тестирование
Тесты написаны с использованием **Pytest** и находятся в папке `tests/`

### CI/CD
Проект настроен с использованием **GitHub Actions** для автоматической сборки и деплоя. Конфигурация находится в папке `.github/workflows/`

Основные этапы CI/CD:

- Запуск тестов

- Сборка Docker образов

- Деплой в test/production окружения
